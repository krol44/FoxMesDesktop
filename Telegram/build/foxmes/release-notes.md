# FoxMes Desktop 1.4.1

This is the first cross-platform FoxMes Desktop release for Windows x64, macOS 13+ on Apple silicon, and Linux x86_64.

The macOS package is arm64-only and will not run on an Intel Mac.

These artifacts are not code-signed or notarized. Windows SmartScreen and macOS Gatekeeper may show a warning. Verify the downloaded file against `SHA256SUMS` and check the GitHub build provenance before launching it.

The release does not include automatic installation, Microsoft Store, Mac App Store, Snap, Flatpak or WinGet packages.

Read and delivery receipts are now tracked separately across FoxMes Desktop and fxl-web. After the server upgrade, some historical conversations may show a one-time increase in unread messages: legacy delivery receipts are intentionally not treated as proof that a person read the message.
