FoxMes Desktop 1.4.3. This is the first cross-platform FoxMes Desktop release for Windows x64, macOS 13+ on Apple silicon, and Linux x86_64.

The macOS package is arm64-only and will not run on an Intel Mac.

These artifacts are not code-signed or notarized. Windows SmartScreen and macOS Gatekeeper may show a warning. Verify the downloaded file against `SHA256SUMS` and check the GitHub build provenance before launching it.

How to sign an application in different operating systems is written here – https://github.com/krol44/FoxMesDesktop?tab=readme-ov-file
